## Why the workflow had CSVs that were not in the repository

The workflow runs the experiment scripts in a clean GitHub Actions workspace and then executes `actions/upload-artifact@v4` with `path: results/`. The workflow therefore **uploads generated results as an Actions artifact but does not commit the generated `results/` directory back to Git**. The repository can consequently contain a partial or older snapshot even though the latest workflow artifact contains newer files.

The workflow explicitly runs the fixed-target experiment plus stopping-rule confound, squares-relatedness, compatibility calibration, relatedness-pairs, retention, signed-domain transfer, and unrelated-parent control experiments. It then uploads the complete generated `results/` directory as artifact `experiment-results`. The latest run completed all stages and the regression suite successfully.
