This document is the **current-final-controller** numerical source for the manuscript. Every publication-facing number below must be traceable to a workflow-generated CSV in `results/`. Historical/pre-fix results are excluded from these tables.

## Table 1 — Fixed-target prerequisite matrix

| Target | No prior skill | Addition only | Addition + multiplication |
|---|---:|---:|---:|
| Subtraction | 33.47 steps | 62.33 steps | 73.20 steps |
| Division | 515.20 steps | 616.20 steps | 621.79 steps |
| Squares | 20.0% success | 20.0% success | 13.3% success |
| Powers | 471.60 steps | 355.20 steps | 237.33 steps |

**Source:** `results/relatedness_pairs_summary.csv`.

For step-based rows, the statistic is the mean budgeted target-adaptation steps over valid target histories. Failed target acquisitions contribute the 1500-epoch cap. Invalid prerequisite histories are excluded because the target is not attempted. The division + addition + multiplication condition has 14/15 valid histories because one prerequisite acquisition failed; all 14 target attempts succeeded.

## Historical results

The repository may retain historical/pre-fix analyses for provenance. They are not authoritative publication evidence. In particular, historical source→target speedup tables must not be presented as though they were generated by the current fixed-target workflow.

## Reproducibility rule

A number may enter the manuscript only if:

1. it appears in a workflow-generated CSV under `results/`, or is deterministically computed from such a CSV;
2. the computation/filtering rule is stated;
3. the corresponding figure, if any, is generated from the same source CSV;
4. the result is labeled current-final-controller or historical.
